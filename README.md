# Font Dock

オープンライセンスのフォントを、好きな文章で比較してダウンロードできるElectronアプリです。

## 起動

Node.js と npm がインストールされた環境で、次のコマンドを実行してください。

```bash
./start.sh
```

初回は必要なパッケージをインストールし、ビルド後にアプリを開きます。終了するにはターミナルで `Ctrl+C` を押してください。

## Webページで試す

ヘッダーの「ブラウザ」またはサイドバーの「Webで試す」から、URLを入力してページを開けます。フォント一覧の各カードにある「Webで試す」からは、そのフォントを選んだ状態でブラウザ画面に移動します。

ブラウザ画面では戻る・進む・再読み込み、フォント名での絞り込み、フォント切り替え、「標準に戻す」が使えます。ログイン情報はアプリ専用のブラウザ領域に保持します。フォントはオンラインで取得し、ページを移動した後も適用します。

URL欄の☆を押すと、現在のページをブックマークバーに登録できます。バーの名前をクリックするとページを開き、横の×で削除できます。ブックマークは次回起動時にも残ります。

変更するのはアプリ内の文字表示だけです。画像内の文字や一部の埋め込み表示は変更できません。サイトによってはログインや表示を制限される場合があります。

## 開発

```bash
npm install
npm run dev
```

ブラウザのみで確認する場合は `npm run dev:web` を使います。ブラウザ版のダウンロードボタンはGoogle Fontsの配布ページを開きます。

## ビルド

```bash
npm run build
npm start
```

掲載フォントはGoogle Fontsで公開されているSIL Open Font Licenseのフォントです。利用時は各フォントに同梱されるライセンス文書を確認してください。
